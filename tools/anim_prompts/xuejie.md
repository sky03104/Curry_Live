# 學姊（xuejie）逐格動畫提示詞（給 Gemini 等生圖工具）

用法：每次都**附上參考圖**（`assets/heroes/xuejie.png`，或你的原圖），貼上「共用規格」＋下面某一個動畫的提示詞。
生成後把圖給 Claude，用 `tools/make_anim_sheet.py` 處理並登記 `heroAnims`。建議命中格：普攻第 5 格、技能第 6 格。

## 共用規格（每個動畫都要貼）
```
角色：附圖裡的長髮女孩「學姊」——戴著灰色連帽（帽子罩在頭上）、黑框圓眼鏡、棕黑色長髮、藍色牛仔外套（袖子捲起）、黑色上衣與黑色短褲、光腳、頸上有細項鍊，一隻手拿著透明塑膠杯的冰抹茶拿鐵（吸管、冰塊、上層奶茶色、下層抹茶綠）。每一格的臉、髮型、服裝、杯子都必須一模一樣。
杯子重要：杯身上不要有任何商標、文字、圖案，只有一個素色深綠色的圓形貼紙。

背景：純綠色 #00FF00，整張圖只有這一種綠色，不要地面、不要陰影、不要漸層。（角色身上不要出現鮮豔的純綠色，抹茶杯維持附圖那種偏橄欖的暗綠色。）

排版：8 格，4 欄 × 2 列，每格一樣大、等距排列，格與格之間留綠色空白；不要格線、邊框、文字、編號。閱讀順序由左到右、由上到下。

每一格：角色全身完整入鏡（含頭髮、帽子、腳，不被切到邊）；角色大小每格一致；腳底站的高度每格一致（跳起來的格除外）。

方向：角色面向畫面右邊（跟參考圖一樣，側面或 3/4 側面）。
鏡頭：跟參考圖一樣的斜上方 3/4 視角，每格鏡頭角度一致。
畫風：跟附圖一樣的精緻可愛插畫風，皮膚與頭髮細緻。
特效：什麼特效都不要畫（不要光、不要線條、不要文字），特效由遊戲自己處理。
```

## 1. 待機（idle）——自拍，8 格，循環播放
```
【貼上共用規格，另外加一條：手機是素色黑色手機，背面沒有任何商標、圖案或文字】

動畫：待機，學姊自拍，8 格，循環播放。一隻手一直拿著飲料，另一隻手拿手機。8 格由左到右、由上到下：
1. 站著，嘴含著吸管，一隻手拿杯子，另一隻手插在外套口袋，眼睛看向前方。
2. 插口袋的手掏出一支素色黑色手機，眼睛看向手機，嘴角微微上揚。
3. 手機舉到臉前面（手機螢幕朝向自己，只看得到手機背面），頭微微歪向一邊，眨一隻眼睛。
4. 比出 YA（剪刀手）擺在臉旁，吐舌頭做鬼臉，眼睛彎成月牙。
5. 換成鴨子嘴（嘟嘴）賣萌，頭歪向另一邊，眼神無辜。
6. 手機放下到胸前，低頭看剛拍的照片，噗哧笑出來。
7. 笑得肩膀抖動，用拿杯子的那隻手擋在嘴巴前面，眼睛瞇成一條線。
8. 手機收回口袋，回到站姿，嘴含回吸管（動作要能接回第 1 格，循環不跳）。
```

（舊版備案：悠哉喝飲料——站著 → 低頭吸吸管 → 滿足瞇眼 → 撥頭髮 → 歪頭，保留在 git 歷史裡。）

## 2. 走路（walk）——悠閒走路，8 格，循環播放
```
【貼上共用規格】

動畫：走路，角色向右邊悠閒走路，8 格循環，第 8 格要能順順接回第 1 格。
全程：一隻手穩穩拿著飲料（杯子隨步伐微微上下），另一隻手插口袋；光腳；長髮與帽子隨步伐輕輕擺動；頭保持穩定看前方。
1. 接觸：前腳（靠畫面前面）向前踩出，腳跟著地，後腳在後面。
2. 下沉：身體微微下壓，長髮往後飄一點。
3. 經過：兩腳在身體下方交會，身體最挺直。
4. 上升：身體微微抬起，後腳向前擺出。
5. 接觸：另一隻腳向前踩出著地（對稱第 1 格）。
6. 下沉：身體微下壓，頭髮擺到另一邊。
7. 經過：兩腳交會，杯子輕輕晃一下。
8. 上升：準備回到第 1 格。
```

## 3. 普攻（attack）——彈指一擊，8 格，第 5 格命中
```
【貼上共用規格】

動畫：普攻，彈指一擊，8 格，第 5 格是命中瞬間。杯子一直拿在原本那隻手上，用另一隻手彈指。
1. 站姿，嘴含著吸管，眼神看向前方。
2. 吐掉吸管，眼神變得銳利，插口袋的手從口袋抽出。
3. 手臂向後拉，食指與拇指扣成彈指的姿勢，身體往後微仰，眉頭皺起。
4. 身體前傾，手臂向前甩出，頭髮與帽子被甩得往後飄。
5. 【命中】食指用力彈出，手臂伸直向前，表情得意、嘴角上揚。
6. 手臂停在最前面，身體重心在前腳，頭髮飛揚。
7. 手收回，身體慢慢回正。
8. 回到站姿，嘴巴又含回吸管，吸一口（接近第 1 格）。
```

## 4. 技能「學姊罩你」（skill）——乾杯鼓舞，8 格，第 6 格施放
```
【貼上共用規格】

動畫：技能，學姊舉杯鼓舞大家，8 格，第 6 格是施放瞬間。
1. 站姿，深吸一口氣，眼神變得自信。
2. 抬起頭，把杯子舉到胸前，另一隻手從口袋抽出。
3. 杯子高高舉過頭（像乾杯），身體挺直。
4. 另一隻手叉腰，下巴微微抬起，笑得自信。
5. 身體微微後仰，帽子與長髮被氣流吹得飄起，衣角飄動。
6. 【施放】拿杯子的手往前（畫面右側）用力一指，另一隻手比出大拇指，身體前傾，開心大笑。
7. 維持指向前方的姿勢，頭髮與外套飛揚，表情自信。
8. 收勢，手放下，回到站姿，嘴含回吸管（接近第 1 格）。
```

## 小提醒
- 一次畫 8 格失敗時，改成**一格一格畫**：每次附上「參考圖＋這個動畫已畫好的第 1 格」，說「同一個角色、同樣大小、同樣背景，畫第 N 格：……」。
- 如果畫面裡杯子又出現商標，請重畫或告訴 Claude，Claude 會再把商標塗掉。
- 有格面向左也沒關係，工具可以單獨翻面。
