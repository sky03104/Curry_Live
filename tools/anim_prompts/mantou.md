# 饅頭（mantou）逐格動畫提示詞（給 Gemini／ChatGPT 等生圖工具）

參考圖：`assets/heroes/mantou.png`（去背後的全身圖；原圖是咖哩給的，灰虎斑胖貓穿紅金鎧甲）。**每次都要真的附上參考圖片檔，不要只貼網址。**
生成後把圖給 Claude，用 `tools/make_anim_sheet.py` 處理並登記 `heroAnims`。建議命中格：普攻第 5 格、技能第 6 格。**優先順序：攻擊、技能、待機、走路。**

## 共用規格（每個動畫都要貼）
```
角色：附圖裡的貓咪武將「饅頭」——灰色虎斑紋的胖貓，綠色大眼睛、白色的圓肚子與白色手掌腳掌，頭戴紅色羽纓的金邊黑紅頭盔（頭盔正面有金色獅頭紋），身穿紅色方格紋鎧甲搭配金色獅頭肩甲與胸甲，紅色圍巾、紅色披風，紅色腰帶上有金色獅頭扣與紅色流蘇，腰間佩著黑金色的劍鞘（劍收在鞘裡），尾巴有深灰色環紋。每一格的臉、紋路、鎧甲、披風、顏色都必須跟附圖**一模一樣**，用跟附圖同樣精緻的可愛插畫風。請嚴格照附圖的角色畫，不是憑想像。

背景：純綠色 #00FF00，整張圖只有這一種綠色，不要地面、不要陰影、不要漸層、不要紅色光暈。（角色身上不要出現鮮豔的純綠色；貓眼睛的綠色維持附圖那種柔和的黃綠色。）

排版：圖片橫式 3:2；8 格，4 欄 × 2 列，每格一樣大、等距排列，格與格之間留綠色空白；不要格線、邊框、文字、編號。閱讀順序由左到右、由上到下。

每一格：角色全身完整入鏡（含耳朵、羽纓、尾巴、腳，不被切到邊）；角色要畫小一點，每格上下左右都留至少 10% 的綠色空白，絕對不能超出格子；角色大小每格一致；腳底站的高度每格一致（跳起來的格除外）。

方向：角色朝向畫面左邊（身體與臉轉向左側，3/4 側面），每格鏡頭角度一致。這是用兩隻後腳站立的胖貓，走路與動作時保持這種「直立走路的貓」的姿態，不要變成四腳著地的貓。
特效：什麼特效都不要畫（不要光、不要線條、不要殘影、不要文字、不要塵土），特效由遊戲自己處理。
```

## 1. 攻擊（attack）——肉球爪擊，8 格
```
【貼上共用規格】
動畫：普攻，用肉球爪子揮擊。8 格由左到右、由上到下：
1. 站著，雙手放在胸前，擺出準備姿勢
2. 一隻手向後拉開，身體微微後仰
3. 肚子往後縮，手臂拉到最後，蓄力到最大
4. 身體向前傾，手臂開始揮出
5. 肉球爪子揮到最前方，打中前方目標（命中瞬間）
6. 揮擊的餘勢，手臂劃過身體另一側，披風向後飄
7. 收回手臂，身體回正
8. 回到第 1 格的準備姿勢（要能接回第 1 格）
```

## 2. 技能（skill）「肉球鎮營」——全身重量壓下去，8 格
```
【貼上共用規格】
動畫：技能「肉球鎮營」。8 格由左到右、由上到下：
1. 站著，雙手握拳放在胸前，準備姿勢
2. 蹲低，身體往下沉蓄力，肚子壓在腿上
3. 雙腿用力一蹬，身體向上跳起（腳離地）
4. 在空中，雙手高舉過頭，肚子朝下，到達最高點
5. 開始下墜，雙手往下壓，披風被風往上吹
6. 重重落地，雙腳著地、雙手往下拍向地面（命中瞬間；不要畫塵土或震波）
7. 落地的餘勢，身體往前傾，肚子晃動
8. 慢慢站直，回到準備姿勢（要能接回第 1 格）
```

## 3. 待機（idle）——呼吸晃動，8 格循環
```
【貼上共用規格】
動畫：待機，8 格循環播放。直立站著，圓滾滾的肚子隨呼吸一起一伏，尾巴輕輕擺動，耳朵偶爾抖一下。8 格由左到右、由上到下：
1. 站定，吸氣，尾巴垂在左邊
2. 肚子微微鼓起，尾巴開始往右擺
3. 吸氣到最高，頭微微抬起，尾巴擺到右邊
4. 開始吐氣，耳朵輕輕抖一下
5. 肚子慢慢縮回，尾巴往左擺
6. 重心微微換到另一隻腳，眼睛眨一下
7. 頭輕輕轉一下看向前方，尾巴垂回中間
8. 回到第 1 格的姿勢（循環不跳）
```

## 4. 走路（walk）——直立走路的胖貓，8 格循環
```
【貼上共用規格】
動畫：走路循環，8 格。用兩隻後腳直立、一搖一擺的走路，肚子與披風隨步伐晃動，雙手自然擺動。8 格由左到右、由上到下：
1. 左腳在前著地，身體微微下沉
2. 重心移到左腳，身體升起，右腳離地
3. 右腳向前擺出
4. 右腳在前著地，身體微微下沉
5. 重心移到右腳，身體升起，左腳離地
6. 左腳向前擺出
7. 左腳繼續向前，接近第 1 格的姿勢
8. 回到第 1 格前一刻的姿勢（循環不跳）
```
