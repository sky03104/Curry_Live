參考圖：`assets/heroes/heart.png`（去背後的全身圖；原圖是咖哩給的，棕髮齊瀏海的女孩，手拿超大彩虹旋渦棒棒糖）。**每次都要真的附上參考圖片檔，不要只貼網址。**
生成後把圖給 Claude，用 `tools/make_anim_sheet.py` 處理並登記 `heroAnims`。建議命中格：普攻第 5 格、技能第 6 格。**優先順序：攻擊、技能、待機、走路。**
⚠️ 參考圖是「從高處往下看」的俯視角度（頭很大、腳很小），動畫請**維持一樣的俯視角度**，這樣跟遊戲裡的單張圖才接得起來。

## 共用規格（每個動畫都要貼）
```

背景：純綠色 #00FF00，整張圖只有這一種綠色，不要地面、不要陰影、不要漸層。（棒棒糖的綠色色條維持附圖那種柔和的黃綠色，不要變成純螢光綠 #00FF00，以免被當成背景吃掉。）

排版：圖片橫式 3:2；8 格，4 欄 × 2 列，每格一樣大、等距排列，格與格之間留綠色空白；不要格線、邊框、文字、編號。閱讀順序由左到右、由上到下。

每一格：角色全身完整入鏡（含頭髮、棒棒糖整支含棒子、腳，不被切到邊）；角色要畫小一點，每格上下左右都留至少 10% 的綠色空白，絕對不能超出格子；角色大小每格一致；腳底站的高度每格一致（跳起來的格除外）。

方向：角色朝向畫面左邊（身體與臉轉向左側），維持跟附圖一樣的俯視角度，每格鏡頭角度一致。
特效：什麼特效都不要畫（不要光、不要線條、不要殘影、不要文字、不要星星、不要塵土），特效由遊戲自己處理。
```

## 1. 攻擊（attack）——超大棒棒糖揮擊，8 格
```
【貼上共用規格】
動畫：普攻，雙手握住超大棒棒糖的棒子，像揮大錘子一樣打人。8 格由左到右、由上到下：
1. 站著，雙手握住棒子，棒棒糖斜扛在肩上，準備姿勢
2. 身體往後仰，棒棒糖往後舉高
3. 蓄力到最大，棒棒糖舉到頭頂後方，身體微微後傾
4. 身體往前傾，雙手開始把棒棒糖往前揮下
5. 棒棒糖揮到最前方，重重打在前面的地上（命中瞬間；不要畫衝擊或塵土）
6. 揮擊的餘勢，棒棒糖壓在地面前方，身體跟著往前傾
7. 慢慢把棒棒糖抬起來，身體回正
8. 回到第 1 格的準備姿勢（要能接回第 1 格）
```

## 2. 技能（skill）「甜蜜重擊」——跳起來用棒棒糖全力砸下去，8 格
```
【貼上共用規格】
動畫：技能「甜蜜重擊」，比普攻更誇張的全力一擊。8 格由左到右、由上到下：
1. 站著，雙手握住棒棒糖，扛在肩上，準備姿勢
2. 蹲低蓄力，棒棒糖往後拉
3. 用力向上跳起（腳離地），棒棒糖跟著舉過頭頂
4. 在空中最高點，雙手把棒棒糖高高舉起，身體伸展
5. 開始下墜，棒棒糖朝前下方揮下來，裙擺被風往上吹
6. 重重落地，棒棒糖砸在地面上（命中瞬間；不要畫塵土或震波）
7. 落地的餘勢，身體往前傾，單膝微彎，棒棒糖壓在地上
8. 慢慢站直，把棒棒糖扛回肩上，回到準備姿勢（要能接回第 1 格）
```

## 3. 待機（idle）——蹲在地上畫圈圈，8 格循環
```
【貼上共用規格】
動畫：待機，8 格循環播放。她蹲在地上，一隻手伸出食指在地上畫圈圈（地面不要畫出來，也不要畫出圈圈的線，只畫手指動作），另一隻手扶著放在地上的超大棒棒糖（棒棒糖斜靠在她身旁）。8 格由左到右、由上到下：
1. 蹲著，低頭看地面，食指伸向地面，棒棒糖斜靠在身旁
2. 手指在地上往左劃出圈的開頭，頭跟著手微微轉向左
3. 手指繞到圈的下方，身體微微前傾
4. 手指繞到右邊，頭轉向右
5. 手指繞回圈的上方，圈快要畫完
6. 畫完一圈，抬頭看一下前方，露出滿意的微笑
7. 又低下頭，手指回到起點，準備再畫一圈，肩膀微微晃動
8. 回到第 1 格的姿勢（循環不跳）
```
