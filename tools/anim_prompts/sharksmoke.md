# 鯊魚煙（sharksmoke）逐格動畫提示詞（給 Gemini／ChatGPT 等生圖工具）

參考圖：`assets/heroes/sharksmoke.png`（去背後的全身圖；原圖是咖哩給的，黑道大哥風的鯊魚穿直條紋西裝、嘴叼雪茄）。**每次都要真的附上參考圖片檔，不要只貼網址。**
生成後把圖給 Claude，用 `tools/make_anim_sheet.py` 處理並登記 `heroAnims`（**原圖與遊戲單張圖都是面向右邊**，所以處理時用 `--faces right`，單張圖已列進 `artFacesRight`）。建議命中格：普攻第 5 格、技能第 6 格。
**優先順序：攻擊、技能、待機一（抽雪茄）、待機二（吃牛排）、走路。**

## 共用規格（每個動畫都要貼）
```
角色：附圖裡的鯊魚武將「鯊魚煙」——灰藍色的鯊魚頭（背鰭、臉上有一道紅色 X 形疤痕、一隻棕色眼睛、白色的肚子與下顎、一排尖牙），身穿黑色直條紋西裝配白襯衫（領口敞開），脖子上掛粗金鍊與圓形金色星形墜飾，胸口別著一朵紅玫瑰（玫瑰有金鍊子垂下），腰間黑皮帶配金色鯊魚鰭造型扣，肩上披著黑色毛皮領的華麗披風（內裡暗紅色花紋、邊緣金色渦紋），手腕戴金色大手錶、手指戴金戒指，腳穿亮面黑皮鞋。身體是圓滾滾的 Q 版大頭矮身比例，用兩隻腳站立。每一格的臉、疤痕、西裝條紋、金飾、披風、顏色都必須跟附圖**一模一樣**，用跟附圖同樣精緻的可愛插畫風。請嚴格照附圖的角色畫，不是憑想像。

背景：純綠色 #00FF00，整張圖只有這一種綠色，不要地面、不要陰影、不要漸層。（角色與道具身上不要出現鮮豔的純綠色。）

排版：圖片橫式 3:2；8 格，4 欄 × 2 列，每格一樣大、等距排列，格與格之間留綠色空白；不要格線、邊框、文字、編號。閱讀順序由左到右、由上到下。

每一格：角色全身完整入鏡（含背鰭、披風、腳，不被切到邊）；角色要畫小一點，每格上下左右都留至少 10% 的綠色空白，絕對不能超出格子；角色大小每格一致；腳底站的高度每格一致（跳起來的格除外）。

方向：角色朝向畫面右邊（身體與臉轉向右側，3/4 側面，跟附圖一樣），每格鏡頭角度一致。

雪茄與煙：雪茄是素色的棕色雪茄，雪茄上不要有任何商標、文字或煙標；只准畫雪茄頭冒出的一小縷淡白灰色細煙（細煙不要太長、不要佈滿整格）。除了這縷細煙以外，不要畫任何特效（不要光、不要線條、不要殘影、不要文字、不要塵土），其他特效由遊戲自己處理。
```

## 1. 攻擊（attack）——張大嘴咬人，8 格
```
【貼上共用規格；這一組雪茄要先從嘴裡拿下夾在手指間（第 2 格開始），免得咬的時候雪茄擋住嘴】

動畫：普攻，用嘴巴張得大大地去咬人。8 格由左到右、由上到下：
1. 站著，嘴角叼著雪茄，一手插口袋，壞笑，準備姿勢
2. 單手把雪茄從嘴裡拿下夾在指間，身體微微往後仰、頭往後縮
3. 身體往後拉到最大，頭高高抬起，嘴巴開始張開，露出尖牙，蓄力
4. 身體猛地向前撲，嘴張到最大（上下顎分開接近 90 度），整排尖牙全露出來
5. 頭伸到最前面，大嘴整個咬下去、上下排牙齒合攏的瞬間（命中瞬間；不要畫血、不要畫牙印特效）
6. 咬完的餘勢，頭還在最前面、嘴巴緊閉，披風向後飄
7. 身體往回收，嘴角帶著得意的笑，舔一下牙
8. 回到第 1 格的準備姿勢（要能接回第 1 格，雪茄回到嘴角）
```

## 2. 技能（skill）「煙霧瀰漫」——吸一口雪茄吐出一大片煙，8 格
```
【貼上共用規格。技能的大片煙霧由遊戲畫，所以第 6～7 格只畫嘴邊吐出的「一小團」煙，不要把整格塞滿煙】

動畫：技能「煙霧瀰漫」，深深吸一口雪茄然後往前吐出大量的煙。8 格由左到右、由上到下：
1. 站著，嘴角叼著雪茄，一手插口袋，準備姿勢
2. 一手把雪茄拿到嘴邊，胸口微微鼓起，開始吸氣，雪茄頭燒得發亮（橘紅色）
3. 用力吸，胸膛整個鼓起來、臉頰凹陷，眼睛瞇起
4. 吸到最飽，胸膛鼓到最大，頭微微後仰，閉嘴憋著
5. 頭往前一甩，嘴巴嘟成圓形，準備往前吐
6. 嘴巴大開，往前用力吐出煙（嘴前只畫一小團白灰色的煙，命中瞬間），披風被氣流吹得往後飄
7. 吐完最後一口，身體稍微前傾，嘴角還飄著一縷煙，滿足地瞇眼
8. 慢慢站直，雪茄回到嘴角，回到準備姿勢（要能接回第 1 格）
```

## 3a. 待機一（抽雪茄，循環）——登記成 `idle`
```
【貼上共用規格】

動畫：待機，一直抽著雪茄，8 格循環播放。站著悠閒地抽，雪茄的煙細細地往上飄。8 格由左到右、由上到下：
1. 站著，一手插口袋，另一手拿著雪茄放在身前，眼神斜睨前方
2. 把雪茄舉到嘴邊
3. 把雪茄叼進嘴裡，吸一口，雪茄頭微微發亮，臉頰稍微凹陷
4. 眼睛微瞇，胸口微微鼓起，一臉享受
5. 把雪茄從嘴裡拿開，頭微微抬起，嘴角張開準備吐氣（嘴前只畫一小縷淡煙）
6. 吐煙，頭微微後仰，披風被輕輕吹動
7. 低頭看一下手上的雪茄，彈一下雪茄灰（灰很小一點，不要畫特效）
8. 雪茄放回身前，回到第 1 格的姿勢（循環不跳）
```

## 3b. 待機二（坐在餐桌前吃牛排，循環）——登記成 `idle2`，兩組待機停下來時隨機挑一組
```
【貼上共用規格，另外加：這一組鯊魚煙是「坐」著的，要畫出一張小餐桌與一張椅子；餐桌上有一個白色盤子，盤子上有一塊厚厚的牛排，鯊魚煙的手上拿著銀色刀叉。餐桌、椅子、盤子都是素色，不要畫桌巾上的文字或商標；桌巾不要用綠色。這一格的桌椅要跟鯊魚煙一起算進「全身」，整組都不要超出格子。雪茄這一組不出現（先放在盤子旁邊的菸灰缸，菸灰缸也要畫素色的）】

動畫：待機，鯊魚煙坐在餐桌前優雅地吃牛排，8 格循環播放。8 格由左到右、由上到下：
1. 坐在餐桌前，雙手各拿刀叉放在桌上，眼睛盯著盤子裡的牛排，嘴角帶笑
2. 左手用叉子叉住牛排，右手拿刀準備切
3. 刀子在牛排上往下切，身體微微前傾
4. 切下一小塊牛排，用叉子叉起來
5. 把叉子舉到嘴邊，嘴巴張開，露出一排尖牙
6. 嘴巴咬住牛排，臉頰鼓起，眼睛瞇成滿意的樣子
7. 咀嚼，頭微微晃動，一臉享受
8. 把叉子放回盤邊，用餐巾擦一下嘴，回到第 1 格的姿勢（循環不跳）
```

## 4. 走路（walk）——黑道大哥搖擺走路，8 格循環
```
【貼上共用規格】

動畫：走路循環，8 格。用兩隻腳走路，身體帶著一點大搖大擺的霸氣，嘴角叼著雪茄，一手插口袋，另一隻手自然擺動，披風與背鰭隨步伐微微晃動。8 格由左到右、由上到下：
1. 右腳踏出，身體微微下沉，披風往後飄
2. 重心移到右腳，身體稍微升起
3. 左腳往前擺動
4. 左腳落地、右腳離地，身體左傾
5. 左腳踏出，身體微微下沉
6. 重心移到左腳，身體稍微升起
7. 右腳往前擺動
8. 右腳落地回到第 1 格附近（循環不跳）
```
