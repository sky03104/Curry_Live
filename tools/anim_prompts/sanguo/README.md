# 三國武將逐格動畫提示詞

> **目前做法（2026-11-16）**：用 ChatGPT 桌面版 Codex 在本機 repo 生圖，一天 3～4 張，先做每隻的攻擊＋技能。步驟與每次執行的指令見 [Codex排程指令.md](Codex排程指令.md)；Gemini 版（`排程指令.md`）因為角色對不上、也不能存檔，暫時不用。（38 隻 × 走路／攻擊／技能／待機）

這個資料夾裡每隻武將一份檔（`<heroId>.md`），裡面有四個動畫的提示詞和參考圖網址。`隊列.md` 排好了每天做哪兩隻（約 19 天）。
提示詞是用 `python3 tools/make_anim_prompts.py` 產生的（要改武器、技能動作、動作描述就改那支腳本再重跑，不要手改 md）。

## 每天怎麼做（手動）
1. 打開 `隊列.md`，找今天第一隻沒打勾的武將，點進它的 md。
2. 對 Gemini：附上參考圖（md 最上面的網址那張圖），貼「共用規格」＋「走路」的內容，生一張 8 格圖。再各生「攻擊」「技能」「待機」。一隻 4 張。
3. 圖存成 `<heroId>_walk.png`、`_attack.png`、`_skill.png`、`_idle.png`，丟給 Claude；Claude 用 `tools/make_anim_sheet.py` 處理、接進 `js/config.js` 的 `heroAnims`，並檢查有沒有商標或切到邊。
4. 把 `隊列.md` 那一列改成 `[x]`。

## 讓 Gemini 自己讀 repo（排程／每天自動）
這個 repo 是公開的，Gemini 可以直接讀網址。每天貼給它（或設成排程指令）：

```
請打開 https://raw.githubusercontent.com/sky03104/Curry_Live/main/tools/anim_prompts/sanguo/隊列.md ，
找出第一隻狀態是 [ ] 的武將，打開它的提示詞檔（隊列裡的連結，網址前綴同上），
照檔案裡的說明：下載「參考圖」，然後依序生成走路、攻擊、技能、待機四張圖（每張都附參考圖，貼「共用規格」＋該動畫內容）。
生成後把四張圖用「<heroId>_walk／attack／skill／idle」命名給我下載。每天只做一隻。
```
⚠️ Gemini 不能直接改 repo 的 `隊列.md`，所以「做完打勾」要你（或 Claude）自己改；排程若沒打勾，它隔天會重做同一隻。建議排程指令改成「第 N 天就做第 N 天那兩隻」，或你每天跟它說今天做哪隻。

## 已知會遇到的狀況（之前做萌國角色的經驗）
- Gemini 一次畫 8 格常常：格子大小不一致、角色被切到邊、格子疊在一起。失敗時改成一格一格畫，每次附上參考圖＋前一格。
- 角色手上的飲料／武器常長出商標或亂碼文字，收到圖我會檢查並塗掉。
- 動作要「循環」：第 8 格要能接回第 1 格。
- 三國武將有兩種單張圖朝向：絕大多數面向左，太史慈面向右（提示詞已處理）。
