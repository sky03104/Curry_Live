# 關平（guanping） 逐格動畫提示詞（蜀・猛將・技能「忠勇護主」）

**參考圖（每次都要附上）**：https://raw.githubusercontent.com/sky03104/Curry_Live/main/assets/heroes/guanping.png
（repo 內路徑：`assets/heroes/guanping.png`）

用法：每個動畫各生一張圖。把「共用規格」＋該動畫的內容一起貼給 Gemini，並附上參考圖。生好的圖用 `guanping_動作.png` 命名（動作＝walk／attack／skill／idle），丟給 Claude 處理。
建議命中格：普攻第 5 格、技能第 6 格。若 Gemini 一次畫不好 8 格，改成一格一格畫（每次都附上參考圖＋前一格）。

## 共用規格（四個動畫都要貼）
```
角色：附圖裡的三國武將「關平」（蜀陣營・猛將），手持「捲雲刀」。每一格的臉、髮型、服裝、盔甲、顏色、武器都必須跟附圖**一模一樣**，用跟附圖同樣精緻的Q版可愛插畫風。

背景：純綠色 #00FF00，整張圖只有這一種綠色，不要地面、不要陰影、不要漸層。（角色身上不要出現鮮豔的純綠色。）

排版：圖片橫式 3:2；8 格，4 欄 × 2 列，每格一樣大、等距排列，格與格之間留綠色空白；不要格線、邊框、文字、編號。閱讀順序由左到右、由上到下。

每一格：角色全身完整入鏡（含頭髮、帽子／頭盔、腳、武器，不被切到邊）；**角色要畫小一點，每格上下左右都留至少 10% 的綠色空白，絕對不能超出格子**；角色大小每格一致；腳底站的高度每格一致（跳起來的格除外）。

方向：角色面向畫面左邊（跟附圖一樣，側面或 3/4 側面），每格鏡頭角度一致。
特效：什麼特效都不要畫（不要光、不要線條、不要殘影、不要文字），特效由遊戲自己處理。
```

## 1. 走路（walk）
```
動畫：走路循環，8 格。沉穩有力的大步行進，身體微微前傾，手臂與腿大幅度擺動，武器握在手中隨步伐輕晃。8 格由左到右、由上到下：
1. 左腳在前著地，身體微微下沉
2. 重心移到左腳，身體升起，右腳離地
3. 右腳向前擺出
4. 右腳在前著地，身體微微下沉
5. 重心移到右腳，身體升起，左腳離地
6. 左腳向前擺出
7. 左腳繼續向前，接近第 1 格的姿勢
8. 回到第 1 格前一刻的姿勢（循環不跳）
```

## 2. 攻擊（attack）
```
動畫：普攻，8 格。用「捲雲刀」攻擊。8 格由左到右、由上到下：
1. 單手持武器，擺出準備姿勢
2. 武器向後拉開
3. 身體扭轉蓄力，武器舉到肩後
4. 向前踏步，武器開始揮出
5. 武器斬到最前方（命中瞬間）
6. 揮擊的餘勢，武器劃過身體另一側
7. 收回武器，身體回正
8. 回到準備姿勢（要能接回第 1 格）
```

## 3. 技能（skill）
```
動畫：技能「忠勇護主」：大刀橫擋在身前護住，再猛地向前砍出。8 格由左到右、由上到下：
1. 準備姿勢
2. 開始蓄力，身體動作預備
3. 蓄力到最大，姿勢最張揚
4. 動作開始發出
5. 動作到最高點／最猛烈
6. 技能施放出去（命中瞬間，不要畫任何光或特效）
7. 餘勢，姿勢維持並緩緩收尾
8. 回到準備姿勢（要能接回第 1 格）
```

## 4. 待機（idle）
```
動畫：待機，8 格循環播放。站姿待機，呼吸起伏，重心在兩腳間輕微轉換，偶爾抬眼看向前方，武器握在手中輕輕晃動。8 格循環：
1. 站定，吸氣
2. 胸口微微升起
3. 吸氣到最高，頭微微抬起
4. 開始吐氣
5. 胸口下沉
6. 重心微微換到另一腳
7. 眼神或頭輕輕轉動
8. 回到第 1 格的姿勢（循環不跳）
```
