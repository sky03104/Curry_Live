# 萌戰三國・直播亂鬥（Curry_Live）

TikTok 直播互動小遊戲：觀眾留言武將名字上場、送禮互打。純網頁，給 OBS 瀏覽器來源使用。

## 怎麼試玩
直接雙擊 `index.html`，右邊會有「假事件面板」，按按鈕模擬觀眾留言和送禮。

## 給 OBS 用
網址最後加上 `?obs=1`（例如 `index.html?obs=1`），就只剩透明背景的遊戲畫面。

## 接真的 TikTok 直播
需要在直播用的電腦上跑一支「橋接程式」，它負責去 TikTok 收留言和送禮，再轉給遊戲。

**第一次要先準備：**
1. 安裝 Node.js：到 https://nodejs.org 下載「LTS」版本，一路按下一步裝完。
2. 把這個專案整包下載到電腦並解壓縮（GitHub 頁面的綠色「Code」按鈕 →「Download ZIP」）。

**每次直播前：**
1. 先在 TikTok 開始直播（要先開播，橋接程式才連得上）。
2. 打開專案裡的 `bridge` 資料夾，雙擊 `啟動.bat`。
3. 照提示輸入你的 TikTok 帳號（不用打 @），按 Enter。看到「✅ 已連上」就成功了。
4. OBS 新增「瀏覽器」來源，網址填 `http://localhost:8081/?obs=1`，寬高填你直播畫面的大小。
5. 直播期間那個黑色視窗不要關。關掉它，遊戲就收不到留言和送禮。

**想先試試整條路通不通：** 雙擊 `啟動.bat` 後不輸入帳號、直接按 Enter，會進入示範模式（自動產生假留言和假禮物），
再用瀏覽器開 `http://localhost:8081/` 看武將有沒有自己動起來。

**TikTok 禮物對應哪個動作：** 在 `js/config.js` 的 `tiktok` 那段，預設照禮物價值分級
（1～4 鑽普攻、5～19 鑽回血、20～99 鑽全場攻擊、100 鑽以上技能）。

## 想調數值
改 `js/config.js`：禮物對應的動作、傷害、血量、復活秒數都在裡面，有中文說明。

詳細規則與檔案說明見 `CLAUDE.md`。
