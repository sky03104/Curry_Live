    點歌設定

    ⚠ 你是用「雙擊檔案」開的網頁，YouTube 播放器會被擋。請改用網址開（例如 GitHub Pages 的網址）。
    用來搜尋歌曲。到 Google Cloud 建專案 → 啟用「YouTube Data API v3」→ 建立「API 金鑰」。免費額度每天約可搜尋 100 次（每次留言點歌搜一次，相同歌名不重複算）。
    主要金鑰當天額度用完才會自動換這一把。⚠ 額度是算在「專案」上，同一個專案的兩把金鑰共用額度，所以備用金鑰要來自不同專案才有用。用多個專案是否符合 YouTube 規定官方沒有明說，風險自己評估。
    只有這個帳號的留言可以用「跳過」「清空」。比對的是帳號代號，不是暱稱，別人改暱稱冒充不了。
    歌名或頻道名稱只要含其中一個字，就不能點。
    這是 YouTube 播放器本身的音量，設定改了 OBS 約 30 秒內自動套用。直播中也可以留言 音量 30（只有你的帳號有效，暫時調整），或按播放器上的 🔉🔊。
    關掉＝畫面上看不到影片，只有聲音、歌名、歌詞和待播清單。
    從這場點的第一首開始照順序放，放完一輪回到第一首。觀眾一點歌，等正在放的這首放完就換觀眾的。重新整理 OBS 後，這場點過的歌會重新累積。

    ③ 貼到 OBS 的網址

    OBS 瀏覽器來源：貼上網址、寬 540 高 760 左右，並勾選「透過 OBS 控制音訊」。要手動操作時，在來源上按右鍵 →「互動」，滑鼠移到畫面上就會出現跳過／清空按鈕。
    ⚠ 網址裡的代號等於密碼（你的 YouTube 金鑰存在雲端，靠這個代號保密），不要貼給別人。
